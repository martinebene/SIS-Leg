# WP-081 - Garantizar cierre FIN de avisos ante carreras entre timers y mutaciones

## Estado documental

`INTEGRADO`

## Objetivo

Corregir la carrera confirmada por ASTRA-002 para que todo período de aviso que alcance Recinto y tenga INICIO institucional genere exactamente un FIN cuando deja de estar visible, aun si el vencimiento temporal coincide con otra mutación serializada.

## Resultado esperado

La frontera temporal nunca pierde el callback de cierre institucional por una coincidencia timer/mutación. Reemplazo, cancelación, expiración y carreras continúan siendo idempotentes y respetan el contrato de WP-078.

## Alcance

- Reproducir la coincidencia exacta entre timer completado y mutación concurrente.
- Corregir la coordinación para que cruzar una frontera temporal vencida ejecute una sola vez los efectos institucionales requeridos.
- Preservar serialización global e idempotencia por aviso/período.
- Cubrir expiración, cancelación, reemplazo y coincidencias temporales.
- Mantener el orden FIN anterior -> INICIO nuevo cuando corresponde.

## Criterios de aceptación

1. Timer y mutación completando simultáneamente no pueden hacer visible un vencimiento sin registrar su FIN.
2. Cada INICIO institucional tiene como máximo un FIN y todo período cerrado tiene exactamente uno.
3. Reemplazo produce FIN del anterior antes de INICIO del nuevo.
4. Cancelación después de expiración no duplica FIN.
5. AMBOS conserva semántica independiente por ranura.
6. Fallo de auditoría conserva política fail-closed aplicable.
7. Eventos recientes continúan mostrando el L3 principal conforme WP-078.
