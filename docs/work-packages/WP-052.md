# WP-052 - Eventos operativos seguros, enriquecidos y legibles

## Estado documental

`APROBADO`

## Objetivo

Convertir la proyección reciente de auditoría consumida por Moderación en una vista operativa segura y rápida de leer, preservando estrictamente el secreto del sentido individual durante la votación.

## Resultado esperado

L1/L2/L3 conservan trazabilidad y filtros, pero la UI no depende de mensajes crudos para hechos sensibles. Los votos L3 muestran concejal/banca y `Voto emitido` mientras el sentido es secreto; cuando la frontera autoritativa permite revelarlo, el mismo hecho visual se enriquece con sentido y emoji.

## Decisiones humanas cerradas

1. Iconos: ✅ positivo, ❌ negativo, 🟡 abstención, ✋ pedido de palabra, ✊ retiro.
2. El emoji se ubica a la derecha del registro y ocupa aproximadamente la altura visual de las dos filas actuales.
3. Durante secreto se conserva identidad de concejal/banca, pero no el sentido del voto ni emoji de sentido.
4. Cuando el sentido individual pasa a ser público, los mismos registros visuales se enriquecen con sentido + emoji.
5. La auditoría CSV durable no se reescribe retroactivamente.

## Alcance

- Introducir una proyección operativa segura para eventos sensibles, derivada del hecho durable y del estado autoritativo vigente.
- Evitar que el frontend dependa de parsear el mensaje crudo para identidad, tipo o sentido.
- Para `VOTO_ORDINARIO_REGISTRADO`, impedir que la API revele el sentido mientras la votación está `EN_CURSO`.
- Tras la frontera vigente de revelado, permitir enriquecer el mismo `seq` con el sentido desde la fuente autoritativa de votos.
- Enriquecer pedido/retiro de palabra con iconografía.
- Mantener filtro acumulativo L3/L2/L1, orden nuevo primero y auto-scroll ya integrado.

## Criterios de aceptación

1. Durante `EN_CURSO`, el estado de Moderación no contiene el sentido individual de ningún voto L3 en campos destinados a UI.
2. El registro visual sí identifica banca/concejal y muestra `Voto emitido`.
3. No hay emoji ✅/❌/🟡 durante secreto.
4. Al habilitarse el revelado, el mismo `seq` se presenta con sentido y emoji correctos.
5. Pedido de palabra muestra ✋ y retiro ✊.
6. Los iconos están a la derecha y no rompen las dos filas existentes.
7. L1/L2/L3 conservan filtrado acumulativo y el evento más nuevo continúa primero.
8. El CSV institucional no se reescribe.
9. El Recinto no recibe accidentalmente datos sensibles nuevos.
10. No se introduce polling ni historia local paralela.
