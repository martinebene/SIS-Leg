# WP-086 - Rechazar NaN e infinitos en todos los temporizadores configurables

## Estado documental

`INTEGRADO`

## Objetivo

Endurecer la validación de `system.toml` para que todos los temporizadores configurables acepten únicamente números finitos no negativos y rechacen `nan`, `inf` y `-inf`.

## Resultado esperado

La configuración inválida falla de forma determinista antes de operar; los valores enteros/decimales finitos válidos conservan su semántica actual.

## Dependencias

- WP-079 `INTEGRADO`: gate de CI reproducible.
- WP-003 `INTEGRADO`: contrato base de carga/validación de configuración.

## Fuentes canónicas obligatorias

- `apps/backend/src/sis_leg_backend/configuracion/cargar_configuracion.py`.
- Modelos de configuración.
- `config/system.example.toml`.
- Tests de carga de configuración.
- Triage Astra ASTRA-005.

## Alcance

- Unificar/endurecer validación de todos los timers existentes para exigir finitud además de no negatividad.
- Rechazar booleanos como hasta ahora.
- Mantener `int | float` finitos y no negativos sin conversiones silenciosas.
- Agregar casos `nan`, `inf`, `-inf` por cada clave aplicable.

## Fuera de alcance

- Cambiar valores por defecto.
- Cambiar unidades o semántica temporal.
- Resolver saltos de reloj civil de HIP-04.
- Rediseñar `system.toml`.

## Componentes previsiblemente afectados

- Cargador de configuración.
- Tests de configuración.
- Comentarios/documentación mínima.

## Criterios de aceptación

1. Todos los temporizadores configurables rechazan NaN e infinitos.
2. Cero, enteros positivos y floats finitos válidos siguen aceptándose según contrato.
3. Booleanos continúan rechazados.
4. Mensajes de error identifican la clave inválida.
5. No se alteran otros campos/configuración.

- `uv run pytest tests/test_cargar_configuracion_sistema.py` y suite backend aplicable.

## Invariantes y restricciones
